УЧЕТ КАНЦЕЛЯРСКИХ ТОВАРОВ (C# / WPF / .NET 8)
==============================================

Приложение переписано на C# (WPF) в точном соответствии с техническим заданием (ТЗ)
и аналогично версии на Python, со следующими улучшениями:
• Современный графический интерфейс на WPF с плавной отрисовкой.
• Наглядная подсветка заканчивающихся товаров (остаток <= минимального).
• Полная совместимость с базой данных SQLite от Python-версии (kancelyariya.db).
• Автоматическое резервное копирование, создание ручных копий и восстановление.
• Экспорт журнала операций в CSV с поддержкой Excel.

ЗАПУСК
  Способ 1: Двойной клик по run_windows.bat в этой папке.
  Способ 2: Запуск готового publish\Kancelyariya.exe напрямую.
  Способ 3: Через консоль:
            dotnet run
            dotnet run -- --demo  (для заполнения демонстрационными данными)

СТРУКТУРА ПАПКИ
  Kancelyariya.sln              — решение Visual Studio / Rider
  Kancelyariya.csproj           — проект C# WPF (.NET 8)
  MainWindow.xaml / .cs         — главное окно (Товары, Журнал операций, Сотрудники, Меню)
  Models/                       — модели данных (Product, Employee, Operation)
  Services/DatabaseStore.cs     — бизнес-логика и работа с SQLite базой данных
  Views/                        — диалоговые окна (товар, операция, сотрудник)
  Kancelyariya.Tests/           — модульные тесты xUnit для проверки всей логики
  publish/                      — скомпилированная готовая версия (с Kancelyariya.exe)
  data/kancelyariya.db          — база данных SQLite
  backups/                      — резервные копии базы
  run_windows.bat               — скрипт быстрого запуска

ОСНОВНЫЕ ВОЗМОЖНОСТИ
  1. Каталог товаров:
     • Просмотр остатков и минимального порога.
     • Быстрый поиск по названию в реальном времени.
     • Фильтр «только заканчивающиеся».
     • Цветовая индикация дефицита («⚠ Пора заказать»).
     • Добавление и изменение номенклатуры.
  2. Операции склада:
     • «Приход» — увеличение остатка с фиксацией накладной/поставщика.
     • «Выдать» — выдача сотруднику с контролем наличия (выдача сверх остатка блокируется).
     • «Списать» — фиксация брака/утери с обязательной причиной.
  3. Журнал операций:
     • История всех действий с датой и временем.
     • Фильтры по типу операции («Приход», «Выдача», «Списание»).
     • Фильтр по получателю и текстовый поиск.
     • Экспорт в CSV.
  4. Сотрудники:
     • Добавление, редактирование и удаление сотрудников.
  5. Надежность и резервные копии:
     • Каждая операция мгновенно сохраняется в SQLite.
     • Автокопия при старте (раз в день) и при выходе (если были изменения).
     • Ручные копии и функция безопасного восстановления через меню «Файл».
