# Учет канцелярских товаров (C# / WPF / .NET 8)

Настольное приложение для складского учета и выдачи канцелярских товаров, написанное на C# (WPF, .NET 8) с использованием SQLite.

## Возможности

- **Каталог товаров:**
  - Просмотр актуальных остатков и минимального порога запасов.
  - Мгновенный поиск по названию.
  - Фильтрация «Только заканчивающиеся».
  - Цветовая индикация дефицита (*Пора заказать*).
  - Добавление, редактирование и удаление номенклатуры.
- **Складские операции:**
  - **Приход:** увеличение остатков с указанием накладной/поставщика.
  - **Выдача:** передача сотруднику с контролем остатков (блокировка выдачи сверх наличия).
  - **Списание:** списание брака или потерь с обязательным указанием причины.
- **Журнал операций:**
  - Полная хронология всех действий с фильтрацией по типу операции и сотруднику.
  - Экспорт журнала в формат CSV (совместим с Microsoft Excel).
- **Справочник сотрудников:**
  - Управление списком сотрудников (добавление, редактирование, удаление).
- **Надежность и резервные копии:**
  - Хранение данных в SQLite (`data/kancelyariya.db`).
  - Автоматическое создание бэкапов (раз в сутки при запуске и при закрытии при наличии изменений).
  - Ручное создание резервных копий и восстановление из меню приложения.

## Структура проекта

```text
├── Models/                  # Модели данных (Product, Employee, Operation)
├── Services/                # Бизнес-логика и работа с SQLite (DatabaseStore.cs)
├── Views/                   # Диалоговые окна (товар, операция, сотрудник)
├── Kancelyariya.Tests/      # Модульные тесты xUnit
├── data/                    # База данных SQLite (kancelyariya.db)
├── backups/                 # Резервные копии базы
├── App.xaml / MainWindow.*  # Графический интерфейс WPF
├── Kancelyariya.csproj      # Файл проекта .NET 8
└── Kancelyariya.sln         # Решение Visual Studio
```

## Требования и запуск

- **.NET 8 SDK** / Visual Studio 2022+ с поддержкой WPF.

### Запуск через консоль:
```bash
dotnet run
```

С заполнением демонстрационными данными:
```bash
dotnet run -- --demo
```

### Запуск тестов:
```bash
dotnet test
```
